# Differences from Atlas Modernization

This is the maintained comparison register. It records confirmed successor differences, explicitly labeled successor requirements where the baseline comparison remains unestablished, and earlier differences that a later decision withdrew. It records intended behavior and design, not completed implementation. Update it whenever an accepted decision changes something inherited from Atlas Modernization. Existing rows should describe the current decision; ADRs retain decision history.

Baseline: the locally inspected Atlas Modernization snapshot at [`8edee4e2743fbf0f85c16dfe638d9222141cf279`](https://github.com/the-Drunken-coder/Atlas-Modernization/tree/8edee4e2743fbf0f85c16dfe638d9222141cf279), reviewed on 20 September 2026. Source links are pinned to that revision. The successor column links to its authoritative decision or design document. A source observation is not a claim that the old behavior was a defect.

## Boundaries of this register

The [stack](../adr/0016-use-go-sqlite-and-openapi-tooling.md) and [Docker organization](../adr/0017-deploy-core-and-plugins-as-docker-containers.md) are selected. Exact tool/spec versions, driver, transfer/streaming mechanisms, private management channel, Plugin manifest/distribution and UI integration remain open. Do not turn research alternatives into accepted differences; storage-format compatibility and route redesigns remain unaccepted hypotheses. The superseded infrastructure-first proposal is successor planning history, not an Atlas Modernization baseline behavior; [ADR-0014](../adr/0014-build-dedicated-atlas-systems.md) records the current dedicated-systems direction.

When recording another difference, verify the old behavior against a named source revision, describe the new observable behavior or ownership rule, and link the accepted decision. If the baseline is unknown, say so rather than claiming a removal. Split distinct behavior changes into separate rows and preserve existing row IDs when updating them. This register covers comparisons identified so far and must grow as further differences are accepted. Retain stable IDs for withdrawn differences and label their current disposition rather than continuing to count them as differences.
