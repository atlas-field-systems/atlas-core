## Provenance

[sources.json](sources.json) records the original path, Git revision, and initial
copy hash for each retained page. Links were adjusted for this layout. The content
was preserved rather than condensed. The original documents remain in place.

The source map documents the extraction. It is not a generator input or a rule
that planning pages must remain identical to the old design.

These pages retain old package paths and commands. They do not make the new
planning area runnable. Historical Plugin links are pinned to their original
revision; update their repository address if the original repository is renamed.
